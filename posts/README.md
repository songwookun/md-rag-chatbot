# posts

블로그 글의 **원본**을 두는 곳입니다. 발행은 velog에 복붙합니다.

```
posts/
  01-임계값-0.6에는-근거가-없었다.md
  02-90여-설정을-재고-두-개만-바꿨다.md
```

## 왜 플랫폼이 아니라 여기에 두나

- **플랫폼 종속이 없다** — 나중에 개인 사이트로 옮길 때 복붙만 하면 됩니다.
- **커밋 히스토리가 증거가 된다** — `실험 커밋 → 결론 커밋 → 글 커밋` 순서가 로그에 남습니다.
  "어떻게 공부했나"에 대한 답이 말이 아니라 로그로 나옵니다.
- **글을 쓰면 구멍이 드러난다** — 설명이 안 되는 부분이 곧 코드의 약한 곳입니다.
  그래서 글 커밋 다음에 코드 수정 커밋이 붙는 경우가 생깁니다.

## 쓰는 순서

1. `docs/experiments/` 의 실험 기록과 노트북에서 재료를 꺼낸다
2. 여기에 초안을 쓴다 → 커밋
3. velog에 복붙해서 발행
4. 발행 링크를 글 상단에 적어둔다

## 규칙

- **코드를 통째로 붙이지 않는다.** 코드는 저장소에 있으니 링크로 대신하고,
  글에는 **판단과 실수**를 남긴다.
- **틀린 결론을 지우지 않는다.** 실험①이 실험②에서 뒤집힌 것처럼,
  어디서 왜 틀렸는지가 결론보다 오래 쓸모 있다.
